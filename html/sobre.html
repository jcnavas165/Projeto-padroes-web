Sobre

O Projeto

Este projeto foi desenvolvido para a disciplina de Padrões Web e explora de forma interativa como a globalização moldou o vocabulário brasileiro. Cada integrante contribuiu com pesquisa, design e desenvolvimento para construir uma experiência interativa e informativa sobre a evolução da nossa língua.
